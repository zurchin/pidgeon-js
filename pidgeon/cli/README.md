# @pidgeon-ai/cli

**Now [`@zurchin/cli`](https://www.npmjs.com/package/@zurchin/cli).** Pidgeon is now Zurchin. This last release of `@pidgeon-ai/cli` only re-exports `@zurchin/cli` 2.7.0 and says so once when it loads:

```
npm install @zurchin/cli
```

Every `PIDGEON_*` variable still works; `ZURCHIN_*` wins when both are set.
