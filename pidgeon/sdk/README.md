# @pidgeon-ai/sdk

**Now [`@zurchin/sdk`](https://www.npmjs.com/package/@zurchin/sdk).** Pidgeon is now Zurchin. This last release of `@pidgeon-ai/sdk` only re-exports `@zurchin/sdk` 2.16.0 and says so once when it loads:

```
npm install @zurchin/sdk
```

Every `PIDGEON_*` variable still works; `ZURCHIN_*` wins when both are set.
